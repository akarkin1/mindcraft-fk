## Round 1: the build (2026-11-04)

| Id | Finding | Decision |
|---|---|---|
| R1-1 | E1: minecraft-data 3.119.0 removed the feature `entityActionUsesStringMapper` and names the actions of 1.21.6 and later `stop_sleeping` (0), `start_sprinting` (1), `stop_sprinting` (2), `start_fall_flying` (6). mineflayer 4.39.0 falls back to the old numbers, so on 1.21.8 and 26.1 `bot.wake()` sent "stop sprinting" (our `leave_bed` hunk never ran: the name is gone) and a sprint sent "start riding jump" (the serializer writes a number as it is: checked). The owner's bot would not get out of bed by itself and never sprinted on the server. | The mineflayer patch writes the names from 1.21.6 on (`bed.js`, `physics.js` sprint and elytra), the old numbers below. A unit test checks the serializer on both versions; E1 proves wake and sprint on a real 26.1 server (SPEC 4.2). |
| R1-2 | E1: the spec was wrong on `features.json` of prismarine-physics 1.11.1: upstream lists 1.21 and 26.1 for `climbUsingJump` only; `climbableTrapdoor` stops at 1.20. | The `climbableTrapdoor` half of the hunk stays with `"1.21", "26.1"`; the `climbUsingJump` half is dropped. SPEC 4.2 corrected. |
| R1-3 | E1: `spawn_entity` carries the same `lpVec3` velocity as `entity_velocity` and 4.39.0 divides it by 8,000 too (the first velocity of an arrow or a dropped item). | The same conditional hunk for both packets. |
| R1-4 | E1: `place_block.js` with 4.39.0 fails at once on a refusal (#4024); the 500 ms timeout now decides only when the server does not answer. | Kept at 500 ms: today's behaviour (rule 24). |
| R1-5 | E1: `package-lock.json` is regenerated by the install but excluded by `.gitignore`. | Stays excluded, as it has always been; the fresh-clone gate installs from `package.json`. |

| R1-7 | E2: SPEC 4.7 asks for at most 3 lines and 360 characters, but the three longest lines of the table are 472 characters together. | The 360 count includes the header and the line breaks (only then the 17,400 budget holds); a line that does not fit is skipped and the next one tried.
